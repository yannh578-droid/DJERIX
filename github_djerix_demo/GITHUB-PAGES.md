# DJERIX — GitHub Pages

Cette version est préparée pour une démonstration sans crédit API.

- Le site fonctionne comme site statique sur GitHub Pages.
- Les outils (calculatrice, pourcentage, moyenne, conversions) fonctionnent localement.
- IA, rédaction et traduction utilisent automatiquement un **mode démonstration** si le serveur DJERIX n'est pas disponible.
- Aucun secret/API key n'est inclus dans ce dépôt.

Pour activer plus tard la vraie IA, il faudra déployer le serveur `server/` séparément et configurer son API key côté serveur.
