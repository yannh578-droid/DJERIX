# DJERIX V11

DJERIX Technologies — Think Beyond. Build Beyond.

## Démarrage local

1. Ouvrir Terminal dans `server/`
2. Installer les dépendances : `npm install`
3. Créer `server/.env` à partir de `.env.example`
4. Ajouter la nouvelle clé OpenAI dans `OPENAI_API_KEY`
5. Lancer : `npm start`
6. Ouvrir http://localhost:3000

La clé API reste côté serveur et n'est jamais placée dans le navigateur.
